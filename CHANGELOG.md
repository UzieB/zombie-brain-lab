# Changelog

All notable changes to this site are recorded here, newest first.

## 2026-10-10
- Removed the change log section from the About page (and its plain-text version); this file and the GitHub history remain the record of changes.
- Region guide: each entry now has a small gray brain icon with that region in yellow; the amygdala and hypothalamus icons are enlarged to be visible, and their entries say so.
- Smaller prefrontal cortex is now drawn so the front of the brain pulls back (with a dashed line at the typical edge), instead of shrinking inside an unchanged outline; both zombies' prefrontal cortex is now drawn at half size.
- Case file pages: region names in the brain report are now clickable and highlight that region in both brains, with the region guide text shown above the brains and a "Back to the report" link; highlighted regions are now bright yellow instead of green (the thalamus is now light blue so it stays distinct); "Predict first" moved up beside the zombie picture to close the gap on wide screens; the two brains stay side by side on phones; the "Control brain" and "Zombie brain" captions line up; "Case file" above the title is now a tag that links back to all the case files.
- Newspaper Zombie now matches the Basic Zombie in walking for a moment after losing its head: added this to its field note and Home behaviors, gave its brain drawing the same thick, braided spinal cord, added the brainstem and spinal cord to its region guide, and added a "How it might walk without a head" section, takeaway, and source (Guertin, 2009). Removed a basal ganglia source note from the Basic Zombie region guide, which doesn't include the basal ganglia.
- Final round of edits: "Observed behaviors" on Home now starts expanded; removed "(optional)" from Predict first and added "Review the field notes and then consider how to explain the zombie's behavior."; added an Original Project Plan page (the project memo, typos fixed), linked from "detailed project plan" on Wrestling with AI; in "Trade-offs we made," the sentence about asking students is no longer marked as human-written, and that section no longer has the authorship note.
- Later the same day: added a site icon (the "Z" from Zombie); added Wrestling with AI to the top menu; replaced the "Start exploring" button with a sentence; removed "This is version 1. Expect mistakes."; merged How This Was Made into Wrestling with AI as its first paragraph; reworded the two table introductions on Wrestling with AI.
- Built the version 1 prototype from Website Text Draft 5 and Front Lawn Design Draft 4: Home, Basic Zombie and Newspaper Zombie case files, About, How This Was Made, Wrestling with AI, Privacy, and Accessibility.
- Added interactive brain drawings (AI-drawn, not yet checked by an expert) with region highlighting and a text region guide.
- Added authorship color coding (purple = written primarily by a human) on About, How This Was Made, and Wrestling with AI, with plain-text versions that label human-written passages.
- Self-hosted fonts (Atkinson Hyperlegible, Bricolage Grotesque, Creepster; SIL Open Font License) and two Plants vs. Zombies images (© Electronic Arts, not covered by this site's license).
- Corrected the Accessibility statement: highlighted brain regions get a thicker outline as well as a color change (they don't change shape).
